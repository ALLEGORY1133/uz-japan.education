# Demo tasvirlar

Bular vaqtincha chizilgan illyustratsiyalar. Haqiqiy fotosuratlar bilan almashtirish usullari:

1. **Admin panel → «Sayt rasm va videolari»** (tavsiya): har bir joy uchun «Almashtirish».
2. **Fayl bilan**: shu papkadagi faylni bir xil nom bilan almashtiring (`fuji.jpg`, `registan.jpg`, ...),
   keyin `docker compose up -d --build web`. Tavsiya: gorizontal JPG, 1600x1000 atrofida, 300 KB gacha.
   Videolar: `sakura.mp4` (katta band), `lanterns.mp4` (ariza foni) — MP4/H.264, 1280x720, 10 MB gacha.

Bepul fotosuratlar: unsplash.com, pexels.com, commons.wikimedia.org (litsenziya/muallifni tekshiring).
